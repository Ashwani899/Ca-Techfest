# Ca-Techfest

Interactive Techfest 2026 campus ambassador promotional web experience.

## Run locally

This repository is a small learning / project workspace. Clone it and open the relevant project files in your editor.

```bash
git clone https://github.com/Ashwani899/Ca-Techfest.git
cd Ca-Techfest
```

Open `index.html` in a modern browser. The page uses local HTML, CSS, and JavaScript files; no package installation is required.

## Project scope

This repository documents the implementation and learning scope represented by the checked-in files. It is not a claim of production readiness, a verified live deployment, or a benchmark result. Validate the project in your own environment before relying on it.
